ManiBlend Version 4.2.3.1

ManiBlend API:
    - bpy.ops.render.render_diff(write_image: bool, buffer_image: bool)
        Renders current animation.
        Args:
            write_image (bool): If True, save image to filesystem according to bpy.context.scene.render.filepath.
            buffer_image (bool): If True, add image to python list at _bpy.manidiff.get_image_list() as a bytes object. 
    - _bpy.manidiff.get_image_list()
        Get current image buffer list.
        Returns:
            list[bytes]: Current image buffer list. 
                            Image is stored as unpremultiplied RGBA float array.
                            Image pixel rows stored from bottom to top, must be flipped prior to use.
    - _bpy.manidiff.clear_image_list()
        Clear current image buffer list.
        This action must be performed before rendering with render_diff.
    - _bpy.manidiff.get_maniblend_version()
        Returns:
            str: current ManiBlend version.
